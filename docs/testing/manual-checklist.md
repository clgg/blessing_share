# 祝福素材分享 App 人工验收清单

## 安装与离线启动

- [ ] 安装 `app-debug.apk` 后，桌面名称显示“祝福素材分享”。
- [ ] 关闭网络后应用仍能进入首页并展示全部本地素材。
- [ ] Android 包名确认为 `com.clg.blessing_share`。

## 屏幕与无障碍

- [ ] 在 360dp 宽度设备上无黄黑溢出条，文字和按钮不被裁切。
- [ ] 在 390×844dp 设备上布局、留白和底栏与设计规范一致。
- [ ] 系统字体调到 1.3 倍后，分类卡、主按钮和菜单仍可读可点。
- [ ] TalkBack 能读出底栏选中状态、分类卡、收藏按钮和 Toast 状态。
- [ ] 关键按钮触控区不小于 52×52dp，底栏三个区域整块可点。

## 首页与素材

- [ ] 首页可看到四个分类、朋友圈九宫格和今日推荐。
- [ ] 四个分类均可进入列表，素材卡均可进入详情。
- [ ] 详情页可收藏、取消收藏，图文和三个主操作完整显示。
- [ ] 分享和保存提示明确包含“演示”，不会声称已真实完成外部操作。

## 收藏与我的

- [ ] 收藏页可按全部、日常、生日、节日、节气筛选。
- [ ] 取消收藏后 6 秒内可点击“撤销”恢复。
- [ ] 空收藏页“去首页看看”可切回首页。
- [ ] “分享历史、保存记录、我的九宫格、使用帮助、意见反馈、隐私与权限、关于我们”均有承接页面。
- [ ] 反馈不填写描述时显示校验信息，成功后清空输入框。
- [ ] 点击游客卡可切换演示登录状态，重启后状态仍保留。

## 九宫格

- [ ] 首页九宫格入口可选择“温暖团圆”和“四季安康”。
- [ ] 预览固定为 3×3，第 5 格显示演示人物图，九格编号为 1–9。
- [ ] “选择照片（演示）”只替换演示状态，不申请真实相册权限。
- [ ] “保存九宫格”生成本地记录并进入三步大字引导。
- [ ] 引导明确说明不会真实保存图片或自动打开微信。

## 数据持久化

- [ ] 收藏、分享/保存历史、九宫格记录和演示登录状态在重启后可恢复。
- [ ] 损坏的本地状态不会阻止应用启动。
- [ ] 连续快速操作不会因首次加载覆盖新记录。
